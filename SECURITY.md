# Security Policy

## Supported version

Security fixes are applied to the current `main` branch. Historical commits,
Preview branches, and local research artifacts are not supported releases.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do
not disclose a suspected vulnerability, credential, private endpoint, or
reproduction containing sensitive data in a public issue or pull request.

Include the affected component, impact, reproduction steps, and the smallest
safe evidence needed to verify the report. Remove API keys, account identifiers,
market data, news archives, and personal information before submitting it.

The project is research and decision support only. A report that suggests the
software can place orders, bypass its Shadow-only boundary, mutate immutable
evidence, access another owner's Assistant data, or consume provider quota
without authorization should be treated as high priority.
